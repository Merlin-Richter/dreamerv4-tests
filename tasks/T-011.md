# T-011 — Position-memory CONSISTENCY metric (D-018)

`critical-claim-verifier` audit, then implement + GT-floor/forgetting calibration, then

## Why (the problem this replaces)

The open-loop GT-matched position error (EXP-011/012 `pos_err`) is a bad memory yardstick —
Merlin rejected it (ESC-008). It conflates two opposite failures and is artifacted:
- **F1 — never tracked** (predicts center/static): high error. *Should fail.*
- **F2 — tracked but desynced** (remembers the moving ball; one finite-precision bounce-timing
  error sends its still-physical trajectory off the true one): also high error. *Should pass —*
  dead-reckoning a chaotic billiard with zero feedback makes exact-GT-match impossible, not a
  memory failure.
- Artifacts: bounded box caps error near chance; bounces fold a desynced prediction back toward
  GT and falsely credit "recovery" (BOARD design caveat).

We want to measure: **does the model retain a coherent, physically-evolving belief about the
hidden ball — its position AND momentum — through occlusion**, crediting F2 and penalizing F1.

## Readout (Merlin, ESC-008) — decode the counterfactual reveal, do NOT probe hidden state

At each occluded step, read the model's *belief* by asking "what would it predict if revealed
now": inject the absolute **curtain-UP action** (`action=0`; `occluded_bouncing.py` confirms the
curtain action is absolute/Markov, so a 1-frame reveal is in-distribution and needs no retrain),
decode the predicted frame, and run the **existing gated `detect_ball`** (revisit_probe.py) to get
believed `(x, y)`. This reuses the trusted detector and sidesteps the state-probe transfer-validity
risk. Velocity is the finite difference `v_k = b_{k+1} − b_k` (Merlin: "dx = x − x_prev").

**Implementation (reuse the probe almost verbatim):** the believed trajectory is obtained by
sweeping the reveal horizon. For a fixed seed, episode `[P up | k down | 1 up]` for k = 1..K_max
shares one deterministic physics trajectory (same seed), so the reveal readouts `b_k` at
increasing k ARE the model's belief at consecutive hidden timesteps — exactly "compare to the one
before." This is `_trial` swept over reveal index; no new rollout machinery. (Seed `generate`'s
noise for the shared-prefix property; small RNG drift between adjacent k only adds finite-diff
noise, which the GT-floor calibration quantifies — not load-bearing.)

## Grounded env physics (from `occluded_bouncing.py` — the scorer's rules, not guesses)

- Speed: `vx,vy ~ U(1.5,3.0)` with random signs, **fixed within an episode, varies per episode**
  → episode speed `S = sqrt(vx²+vy²) ∈ ~[2.1, 4.2]`. `S` is a per-episode env parameter (read from
  saved `states`); using it as the reference is fair ("how fast it moves in the env"), it is not
  the answer to "where is the ball."
- Reflection is **per-axis**: x-wall flips `vx` only, y-wall flips `vy` only, corner flips both
  (Merlin's edge intuition, confirmed). Walls at `x,y ∈ [10, 53]` (radius 10, 64px).
- **Bounce clamps position to the wall** → at a bounce frame the finite-diff displacement
  *shrinks* (magnitude dips below `S`), not only flips sign. The scorer must allow a magnitude dip
  at the bounce frame, not just a sign flip (Merlin: "be careful how the env works").
- Physics advances every frame even under the curtain; GT `[x,y,vx,vy,curtain]` saved per frame
  (used only for the onset-anchor, the report-only tracking horizon, and calibration — never in the
  consistency score itself).

## The score

Two-part, so it credits F2 and catches both forms of F1:

1. **Onset anchor (ties the belief to the REAL ball; fair vs GT, in-window).** Over the early
   occluded steps while the visible prefix is still in the N-window, the believed `(x,y)` and
   believed velocity must match GT `(x,y,vx,vy)`. Catches: F1-static (believed `|v|≈0 ≠ S`) and
   forgetting (mismatch once prefix scrolls out). Also stops a *hallucinated* coherent-but-wrong
   trajectory from passing part 2 (it would mismatch the observed onset velocity). **[This anchor's
   sufficiency against hallucinated-momentum is the #1 thing to verify — see audit.]**

2. **Self-consistency (GT-free, desync-immune — the F2-crediting core).** Headline: **best-fit
   constant-speed billiard residual** — fit a billiard trajectory (free: `x0,y0,θ0`; fixed speed `S`;
   known walls/clamp) to the believed positions `{b_k}` and report `mean_k ||b_k − fit_k||`. Low ⟺
   the belief traces a physical ball at env speed, bouncing at the walls — even if that path has
   diverged from the true GT path (F2). Fitting over `(x0,y0,θ0)` (not a single noisy finite-diff
   `v0`) is robust to detector noise (~0.65px → ~30% on a single-step `v0`).
   - Interpretable diagnostic (Merlin's local form, reported alongside): per-step speed error
     `||v_k| − S|` and off-wall direction persistence (sign/angle of `v_k` vs `v_{k-1}`), with the
     wall-aware exception (sign flip + magnitude dip allowed within `radius+S+tol` of a wall; corner
     = both axes). The best-fit residual is the global integral of this local rule with exact wall
     handling; lead with it, keep the local stats for debugging.

3. **GT-tracking horizon (report-only, not pass/fail):** first step `||b_k − g_k||` exceeds a
   threshold. Fair while it lasts (EXP-011 showed FF7 ~12 steps); informative, not scored.

## Controls + the validation gate (Merlin's idea, made two-sided)

The scorer must be validated **before** it touches any model — a good instrument gives:
- **GT-floor (must score ~0):** run the consistency score on the *real env GT trajectories*. Real
  physics is self-consistent, so residual ≈ its floor; this calibrates the pass threshold AND
  quantifies the unavoidable residual from wall-clamp + detector discretization (so we don't assume
  zero). *(Merlin: "test the score by checking real env rollouts have very low score.")*
- **Forgetting surrogates (must score HIGH):** frozen-ball (believed position constant → `|v|≈0`)
  and shuffled-position trajectories. A scorer that gives GT≈floor and forgetting≫floor is
  validated; one that doesn't is broken regardless of model results.
- Model-facing controls (as in revisit_probe): **ceiling** (teacher-forced visible reveal — should
  be self-consistent), **chance** (curtain-only context), **copy-last** (frozen ball — must FAIL the
  onset velocity anchor).

## Acceptance / freeze gate

- GT-floor ≈ low, forgetting surrogates ≫ floor (two-sided instrument validation passes).
- Onset anchor flags copy-last/frozen as forgetting; verifier confirms anchor is sufficient against
  a hallucinated-momentum belief (or the metric is revised before freeze).
- Detector gate green (reuse `validate_detector_on_gt`).
- Then FREEZE at a named commit (like the revisit probe @ 5503e75); record in README + DECISIONS.
- Only then: run on `vanilla_s0` (H3 baseline) + FF7 k1/k3, present-then-stop.

## Open question for Merlin (the one framing decision that's his)

Part 2 credits a belief that is internally physical (right speed, real bounces) but has **diverged
from the true GT trajectory** (butterfly) as "memory." This is the direct consequence of his
ESC-008 point and I believe it's correct — but it's the spine of every position claim, so it's his
to lock: **count self-consistent-but-GT-diverged as memory, or require staying near GT for a fair
early window too?** (The onset anchor + report-only tracking horizon already capture the "near GT
early" part; the question is only whether late divergence is forgiven.)

## Risks / would-change-my-mind (for the verifier)

1. **Hallucinated-momentum pass:** a model that draws a coherent moving ball at env speed with a
   *made-up* initial state could pass part 2. Claim: the onset anchor (part 1) kills it. *Verify.*
2. **Reveal readout invalid:** if the model can't render a clean ball on the 1-frame counterfactual
   reveal even when it HAS the info (ceiling control fails detector), the readout is unusable →
   fall back to a state-probe (with its transfer caveat). *Check ceiling first.*
3. **Best-fit residual degenerate:** if some forgetting surrogate still fits a billiard path within
   floor, the fit is too flexible → constrain (fix speed `S`, limit `θ0` grid) or revert to the
   local per-step form. *The forgetting-surrogate gate is the test.*
