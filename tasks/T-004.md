# T-004 — Pre-registered H2/H3 success criteria (LOCKED)

Status: **locked** 2026-06-12 (Merlin-approved, ESC-004; decision D-012).
These criteria were registered with the H2 baseline (EXP-009) read but **before any H3
method exists** — so the H3 bar is genuinely pre-registered. Any change is a new decision.

## Probe (the fixed yardstick)
`src/probe/revisit_probe.py`, frozen (see README freeze commit). Episode =
`[P=3 visible up | n_occ curtain down | 1 reveal up]`, pure generation, window N=8.
Models: `trained_autoencoder.pt` (frozen tokenizer) + the model under test.

## Metrics
- **Headline:** ball **color ΔRGB** at the reveal frame, **occluded vs. matched-horizon
  drift** (curtain-up rollout at the same reveal index). Differencing isolates memory loss
  from ordinary autoregressive drift.
- **Validating secondary:** latent-token MSE (predicted reveal latent vs frozen GT latent),
  decoder/detection-free. Trustworthy iff it tracks color (EXP-009: Pearson r = 0.952).
- **Position:** reported, but **drift-confounded** (EXP-009: occluded ≈ drift) → NOT a
  success metric.
- **Failure mode:** `ball_lost_rate` (no detectable ball) tracked separately.
- **Gate:** detector validated on GT each run; if it fails, numbers are not trustworthy.

## Reference levels (EXP-009 baseline, N=8, P=3, 64 eps/n_occ)
- Ceiling (full-visible): color ΔRGB **15.9**, latent-MSE 0.27.
- Chance (curtain-only context): color ΔRGB **109.9**, latent-MSE 0.88.
- Halfway ceiling→chance: color ΔRGB ≈ **63**.

## Pass/fail definitions
- **H2 (baseline, MET by EXP-009):** vanilla sliding-window recall = chance once the
  color-carrying prefix scrolls out of the window (here n_occ ≥ 7). No retention past N.
- **H3 method success:** at n_occ ∈ **{12, 16, 24}** (well beyond the window), color ΔRGB
  **< ~63** (below halfway to chance) under the identical frozen probe + matched-drift
  control. A method that only helps for n_occ ≤ window does NOT count (that's not memory).
